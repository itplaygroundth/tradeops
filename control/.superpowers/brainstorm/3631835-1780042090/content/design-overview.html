New Endpoints (server.js)

GET /api/mt5/account → balance, equity, margin, profit
GET /api/mt5/positions → open positions list
GET /api/mt5/price/:symbol → bid/ask live price
GET /api/mt5/status → bridge online/offline
POST /api/mt5/order → place buy/sell order

Dashboard Changes (App.jsx)

  • Overview tab: แทน hardcode balance ด้วย MT5 account data
  • Forex tab: ราคา live จาก MT5 แทน external API
  • เพิ่ม MT5 Positions section — แสดง open trades
  • Transaction form: ส่ง order ผ่าน /api/mt5/order
  • Status bar: แสดง MT5 connection status + "Last updated" timestamp

Offline Handling

  • server.js cache ข้อมูลล่าสุดใน memory
  • ถ้า bridge ไม่ตอบ → return cached data + {"mt5_status":"offline","cached_at":"..."}
  • App.jsx แสดง ⚠ MT5 Offline — showing stale data banner
