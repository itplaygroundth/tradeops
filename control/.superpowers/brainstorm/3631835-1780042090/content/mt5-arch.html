Architecture: Node.js server คุยกับ MT5 ยังไง?

Python bridge (mt5_bridge) รันแยก — Node.js จะ proxy ไปหามันอย่างไร?

A

Node.js Proxy (Recommended)

server.js เพิ่ม /api/mt5/* endpoints ที่ proxy ไปหา Python bridge http://127.0.0.1:8888 — dashboard ไม่รู้จัก MT5 โดยตรง

ข้อดี

  • เปลี่ยน backend ได้ไม่กระทบ frontend
  • Node.js ทำ auth/validation ก่อนส่งไป MT5

ข้อเสีย

  • latency เพิ่ม 1 hop
B

Frontend Direct

App.jsx เรียก Python bridge โดยตรงจาก browser (ต้องเปิด CORS บน Python)

ข้อดี

  • ง่ายกว่า — ไม่ต้องแก้ server.js มาก

ข้อเสีย

  • expose MT5 bridge port ออก browser ตรงๆ
  • CORS config ยุ่งยาก
C

Replace server.js data with MT5 data

แทน hardcode ใน server.js ด้วยการดึงจาก MT5 bridge ทุก endpoint ที่มีอยู่แล้ว

ข้อดี

  • frontend ไม่ต้องเปลี่ยนเลย

ข้อเสีย

  • ข้อมูล MT5 (forex positions) ≠ portfolio structure ปัจจุบัน (funds/crypto/forex)
